## Config generation (`docusaurus.config.ts`)

```ts
const inst = loadInstances();                              // parse + validate instances.yaml
plugins: inst.map(i => ['@docusaurus/plugin-content-docs', {
  id: i.id, path: i.path, routeBasePath: i.route,
  sidebarPath: `./sidebars/${i.id}.ts`,                    // must exist before config load: created by scripts/gen-sidebars.mjs
  onlyIncludeVersions: limitVersions(i),                   // newest N + 'current' in dev
  lastVersion: latestLine(i),
  editUrl: …,
}]),
themeConfig.navbar.items: [
  { type: 'doc', docId: 'introduction/index', label: 'CCF' },
  ...inst.filter(i => i.navbar).flatMap(i => [
    { type: 'docSidebar', docsPluginId: i.id, sidebarId: 'main', label: i.label },
    { type: 'docsVersionDropdown', docsPluginId: i.id, position: 'right' }]),   // dropdown shown on that instance's pages
  { to: '/catalog', label: 'Catalog' },
]
```

Plugin instance pages carry their own version dropdown through a swizzled `DocVersionBanner`/sidebar header (navbar keeps only product dropdowns to avoid 50 items).

### Sidebar generation

Docusaurus treats `sidebarPath` as an existing file; it doesn't create one. `scripts/gen-sidebars.mjs` runs as the `prestart` and `prebuild` package scripts (so `yarn start`/`yarn build` always run it first, in CI too). For every instance in `instances.yaml` without a committed `sidebars/<id>.ts`, it writes:

```ts
export default { main: [{ type: 'autogenerated', dirName: '.' }] };
```

Generated files are gitignored; an instance that needs a curated sidebar commits its own file, which the script never overwrites.

## OpenAPI rendering

`docusaurus-plugin-openapi-docs` + `docusaurus-theme-openapi-docs`: one config entry per api version line, `specPath: openapi/api/<line>.yaml`, `outputDir: api_versioned_docs/version-<line>/reference` (current: `api/reference`). Generated MDX is committed (reviewable diffs), regenerated by `yarn gen-api-docs`.

## Versioning rules (enforced by docs-release and `DOCS-VER-*` review rules)

- One version per **minor line** (`0.21`); patch releases edit the line in place.
- `scripts/cut-version.sh <id> <major.minor>` wraps `docusaurus docs:version:<id>` and updates `openapi/` for api.
- Archiving: lines beyond `onlyIncludeVersions` are excluded from the build and listed on an "Older versions" page linking to the archived static build of that line (built once, published under `/archive/<id>/<line>/`).

## STYLE.md

Sections: audience and voice; page skeletons (release notes, config reference row format, feature guide, upgrade guide, plugin page, policies catalog); **media** (prefer GIF over prose for UI flows; ≤ 4 MB, ≤ 20 s, 1280 px; seeded showcase data only; path `static/img/<instance>/<line>/`); links (relative within a version; never link a versioned page to `current`); terminology (glossary terms); i18n notes (source language English).
